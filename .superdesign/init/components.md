# Shared components

The project is a vanilla HTML/CSS/JavaScript application. It has no shared
component directory or component library. Controls such as buttons, inputs,
cards, and tables are authored inline in each page.

For the administrative-panel target, the reusable visual primitives are
currently CSS selectors in `public/admin.html`: `button`, `input`, `select`,
`.card`, and `table`. Their complete source is recorded in `theme.md`.
